# Примеры визуализации данных

В ходе выполнения лабораторных работ и РГР я применял следующие виды анализов данных:

## Дескриптивный анализ

Дескриптивный анализ - это первичное исследование данных, цель которого кратко описать и обобщить их ключевые характеристики.

**Визуализации, которые применяются в дескриптивном анализе:**

- **Гистограмма и график плотности**: Для визуализации распределения одной непрерывной переменной (например, возраст клиентов, сумма покупки).
  - Примеры: [`laba1/img/histogram_возраст_дома.png`](laba1/img/histogram_возраст_дома.png), [`laba1/img/histogram_стоимость_за_м^2.png`](laba1/img/histogram_стоимость_за_м^2.png)
  - Распределения по классам: [`laba2/distributions_by_class.png`](laba2/distributions_by_class.png)
  - Распределения переменных: [`laba3/распределения_переменных.png`](laba3/распределения_переменных.png)
  - Распределения признаков: [`rgr/photos/распределения_признаков.png`](rgr/photos/распределения_признаков.png)

- **Боксплот (ящик с усами)**: Для отображения медианы, квантилей, размаха и выбросов.
  - Примеры: [`laba1/img/boxplot_возраст_дома.png`](laba1/img/boxplot_возраст_дома.png), [`laba1/img/boxplot_стоимость_за_м^2.png`](laba1/img/boxplot_стоимость_за_м^2.png)
  - Анализ выбросов: [`laba1/img/outliers_analysis_возраст_дома.png`](laba1/img/outliers_analysis_возраст_дома.png), [`laba1/img/outliers_analysis_стоимость_за_м^2.png`](laba1/img/outliers_analysis_стоимость_за_м^2.png)

- **Столбчатая и круговая диаграмма**: Для отображения частот категориальных переменных (например, количество клиентов по регионам).
  - Таблица сопряженности: [`laba1/img/contingency_table_C_H.png`](laba1/img/contingency_table_C_H.png)

## Корреляционный анализ

Корреляционный анализ - оценить силу и направление линейной связи между переменными.

**Визуализации, которые применяются в корреляционном анализе:**

- **Матрица диаграмм рассеяния (Scatter Plot Matrix)**: Набор попарных графиков рассеяния для нескольких переменных.
  - Примеры: [`laba2/pairplot_scatter.png`](laba2/pairplot_scatter.png), [`laba2/key_scatter_pairs.png`](laba2/key_scatter_pairs.png)
  - Pairplot по классам: [`rgr/photos/pairplot_по_классам.png`](rgr/photos/pairplot_по_классам.png)
  - Категоризованные диаграммы рассеивания: [`rgr/photos/категоризованные_диаграммы_рассеивания.png`](rgr/photos/категоризованные_диаграммы_рассеивания.png)

- **Тепловая карта корреляционной матрицы (Heatmap)**: Самый популярный способ. Цветом (часто от синего/зеленого к красному) кодируется коэффициент корреляции между всеми парами переменных.
  - Примеры: [`laba2/correlation_matrix.png`](laba2/correlation_matrix.png), [`laba3/корреляционная_матрица.png`](laba3/корреляционная_матрица.png), [`rgr/photos/корреляционная_матрица.png`](rgr/photos/корреляционная_матрица.png)

- **График рассеяния (Scatter Plot) с линией тренда**: Для двух переменных. Может включать доверительные интервалы.

## Регрессионный анализ

Регрессионный анализ - смоделировать зависимость одной переменной от одной или нескольких независимых переменных.

**Визуализации, которые применяются в регрессионном анализе:**

- **График рассеяния с линией регрессии**: Для простой линейной регрессии.

- **График остатков (Residuals vs Fitted Plot)**: Для проверки предположений модели (гомоскедастичность, линейность).

- **График Квантиль-Квантиль остатков (Q-Q Plot)**: Это диаграмма рассеяния, которая сравнивает квантили распределения ваших остатков с квантилями идеального нормального распределения.
  - Примеры: [`laba1/img/qq_plot_возраст_дома.png`](laba1/img/qq_plot_возраст_дома.png), [`laba1/img/qq_plot_стоимость_за_м^2.png`](laba1/img/qq_plot_стоимость_за_м^2.png)

## Дисперсионный анализ

Дисперсионный анализ - метод в математической статистике, направленный на поиск зависимостей в экспериментальных данных путём исследования значимости различий в средних значениях.

**Визуализации, которые применяются в дисперсионном анализе:**

- **Боксплоты по группам**: Показывает медианы, разброс и выбросы для каждой группы. Линии соединяют медианы для наглядности сравнения.

- **Многослойная гистограмма или график плотности**: Для сравнения формы распределений в разных группах.
  - Многослойная гистограмма (однофакторный ANOVA): [`laba1_r/img/histogram_density_by_groups.png`](laba1_r/img/histogram_density_by_groups.png)
  - График плотности (однофакторный ANOVA): [`laba1_r/img/density_plot_by_groups.png`](laba1_r/img/density_plot_by_groups.png)
  - Многослойная гистограмма (двухфакторный ANOVA): [`laba1_r/img/histogram_2factor_anova.png`](laba1_r/img/histogram_2factor_anova.png)
  - График плотности (двухфакторный ANOVA): [`laba1_r/img/density_2factor_anova.png`](laba1_r/img/density_2factor_anova.png)

## Факторный анализ

Факторный анализ - многомерный метод, применяемый для изучения взаимосвязей между значениями переменных.

**Визуализации, которые применяются в факторном анализе:**

- **График каменистой осыпи (Scree Plot)**: Показывает собственные значения факторов. Помогает выбрать число значимых факторов (точка "излома").
  - Пример: [`laba3/график_каменистой_осыпи.png`](laba3/график_каменистой_осыпи.png)

- **Тепловая карта факторных нагрузок**: Аналогична тепловой карте корреляций, но показывает связь переменных с латентными факторами.
  - Пример: [`laba3/матрица_факторных_нагрузок.png`](laba3/матрица_факторных_нагрузок.png)

- **Диаграммы рассеивания факторов**: Визуализация взаимосвязей между факторами.
  - Пример: [`laba3/диаграммы_рассеивания_факторов.png`](laba3/диаграммы_рассеивания_факторов.png)

## Решение задачи классификации

Классификация - отнести объект к одному из заранее известных классов.

**Визуализации, которые применяются при решении задачи классификации:**

- **Матрица ошибок (Confusion Matrix) в виде тепловой карты**: Наиболее наглядно показывает True/False Positive/Negative.
  - Примеры MLP: [`laba2/confusion_matrix_mlp_train.png`](laba2/confusion_matrix_mlp_train.png), [`laba2/confusion_matrix_mlp_test.png`](laba2/confusion_matrix_mlp_test.png), [`laba2/confusion_matrix_mlp_reduced.png`](laba2/confusion_matrix_mlp_reduced.png)
  - Примеры SVM: [`laba2/confusion_matrix_svm_train.png`](laba2/confusion_matrix_svm_train.png), [`laba2/confusion_matrix_svm_test.png`](laba2/confusion_matrix_svm_test.png)

- **ROC-кривая и AUC**: График зависимости True Positive Rate от False Positive Rate при варьировании порога классификации. Площадь под кривой (AUC) — метрика качества.
  - Пример: [`laba2/roc_curves.png`](laba2/roc_curves.png)

- **Граница решений (Decision Boundary)**: Для 2D или 3D данных. Визуализация областей пространства признаков, которые модель относит к разным классам.

- **График важности признаков (Feature Importance)**: Для tree-based моделей (Random Forest, XGBoost).
  - Примеры: [`laba2/feature_importance.png`](laba2/feature_importance.png), [`rgr/photos/важность_признаков.png`](rgr/photos/важность_признаков.png)

- **График результатов настройки параметров**: Визуализация влияния гиперпараметров на качество модели.
  - Пример: [`laba2/parameter_tuning_results.png`](laba2/parameter_tuning_results.png)

## Решение задачи кластеризации

Кластеризация - разделить объекты на группы (кластеры) без предварительно известных классов на основе схожести признаков.

**Визуализации, которые применяются при решении задачи кластеризации:**

- **Многомерное шкалирование (MDS) или t-SNE / UMAP**: Методы уменьшения размерности для визуализации кластеров в 2D/3D, когда признаков много.
  - PCA визуализация: [`rgr/photos/pca_визуализация.png`](rgr/photos/pca_визуализация.png)

- **Дендрограмма**: Для иерархической кластеризации. Показывает процесс объединения кластеров в древовидной структуре.
  - Пример: [`rgr/photos/дендрограмма.png`](rgr/photos/дендрограмма.png)

- **Параллельные координаты (Parallel Coordinates)**: Каждый объект — линия, проходящая через оси-признаки. Цветом выделяются кластеры. Позволяет понять, по каким признакам кластеры различаются.

- **Визуализация результатов кластеризации**: Графики результатов K-means и иерархической кластеризации.
  - K-means результаты: [`rgr/photos/kmeans_результаты.png`](rgr/photos/kmeans_результаты.png)
  - Иерархическая кластеризация: [`rgr/photos/hierarchical_результаты.png`](rgr/photos/hierarchical_результаты.png)
  - Выбор оптимального K: [`rgr/photos/kmeans_выбор_k.png`](rgr/photos/kmeans_выбор_k.png)
  - Влияние параметров: [`rgr/photos/влияние_параметров_k.png`](rgr/photos/влияние_параметров_k.png), [`rgr/photos/влияние_инициализации.png`](rgr/photos/влияние_инициализации.png)
  - Сравнительный анализ: [`rgr/photos/сравнительный_анализ.png`](rgr/photos/сравнительный_анализ.png)

- **Графики силуэтного анализа**: Оценка качества кластеризации.
  - Примеры: [`rgr/photos/silhouette_kmeans.png`](rgr/photos/silhouette_kmeans.png), [`rgr/photos/silhouette_hierarchical.png`](rgr/photos/silhouette_hierarchical.png)

## Поиск ассоциативных правил

Поиск ассоциативных правил - найти закономерности типа "если X, то Y" в транзакционных данных.

**Визуализации, которые применяются при поиске ассоциативных правил:**

- **Граф (Сеть) правил**: Узлы — товары/атрибуты, ребра — связи между ними в правилах. Толщина ребра может отражать поддержку (support) или достоверность (confidence).

- **Матричная диаграмма (Matrix Visualization)**: Товары по осям, а ячейки показывают частоту совместного появления.

- **Группированная столбчатая диаграмма**: Для отображения топ-N правил, сгруппированных по правой части (RHS), где столбцы показывают меру (поддержку, достоверность, лифт).

## Анализ временных рядов

Анализ временных рядов - выявить структуру и закономерности во временных данных.

**Визуализации, которые применяются при анализе временных рядов:**

- **Линейный график (Line Plot)**: Основной график для отображения динамики ряда.
  - Пример: [`laba5/photos/time_series_line.png`](laba5/photos/time_series_line.png)

- **График сезонной декомпозиции**: Ряд разбивается на тренд, сезонность и остаток, которые отображаются на отдельных subplot'ах.
  - Пример: [`laba5/photos/seasonal_decomposition.png`](laba5/photos/seasonal_decomposition.png)

- **Автокорреляционная функция (ACF) и Частичная автокорреляционная функция (PACF)**: Стрелковые диаграммы, помогающие идентифицировать параметры моделей (AR, MA).
  - Пример: [`laba5/photos/acf_pacf.png`](laba5/photos/acf_pacf.png)

- **Календарная тепловая карта (Calendar Heatmap)**: Для выявления внутринедельных и внутримесячных паттернов (например, активность пользователей).
  - Пример: [`laba5/photos/calendar_heatmap.png`](laba5/photos/calendar_heatmap.png)

- **График с прогнозом и доверительным интервалом**: Фактические значения, прогноз на будущее и область неопределенности.
  - Пример: [`laba5/photos/forecast.png`](laba5/photos/forecast.png)
