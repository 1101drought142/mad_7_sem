# Ответы на вопросы для защиты лабораторной работы по классификации

## 1. Постановка задачи классификации. Ограничения, накладываемые на исходные данные. Требования к исходным данным при использовании того или иного метода. Бинарная классификация. Многоклассовая классификация.

### Постановка задачи классификации

**Классификация** — это задача машинного обучения, направленная на отнесение объектов к одному из заранее определенных классов на основе их признаков.

**Формальная постановка:**
- Дано: обучающая выборка $\{(x_1, y_1), (x_2, y_2), ..., (x_n, y_n)\}$, где $x_i$ — вектор признаков, $y_i$ — метка класса
- Требуется: построить функцию $f: X \rightarrow Y$, которая для нового объекта $x$ предсказывает его класс $y$

### Ограничения и требования к исходным данным

**Общие требования:**
1. **Наличие меток классов** — для обучения с учителем необходимы размеченные данные
2. **Репрезентативность выборки** — данные должны отражать реальное распределение классов
3. **Балансировка классов** — дисбаланс классов может привести к смещению модели
4. **Качество признаков** — отсутствие пропусков, выбросов, мультиколлинеарности
5. **Достаточный объем данных** — зависит от сложности задачи и метода

**Специфические требования по методам:**

- **kNN**: требует нормализации признаков, чувствителен к масштабу
- **SVM**: эффективен при небольшом объеме данных, требует нормализации
- **Деревья решений**: могут работать с категориальными признаками, устойчивы к выбросам
- **Нейронные сети**: требуют больших объемов данных, нормализации, числовых признаков
- **Дискриминантный анализ**: требует нормального распределения признаков, отсутствия мультиколлинеарности

### Бинарная классификация

**Бинарная классификация** — задача с двумя классами (например, спам/не спам, болен/здоров).

**Особенности:**
- Проще для интерпретации результатов
- Метрики: accuracy, precision, recall, F-мера, AUC-ROC
- Многие алгоритмы изначально разработаны для бинарной классификации

### Многоклассовая классификация

**Многоклассовая классификация** — задача с тремя и более классами.

**Стратегии решения:**
1. **One-vs-Rest (OvR)**: для каждого класса строится бинарный классификатор (класс vs все остальные)
2. **One-vs-One (OvO)**: строится классификатор для каждой пары классов
3. **Прямое решение**: некоторые алгоритмы (деревья решений, kNN, нейронные сети) поддерживают многоклассовую классификацию напрямую

**Метрики:**
- Macro-averaged: усреднение метрик по всем классам
- Micro-averaged: агрегация всех TP, FP, TN, FN
- Weighted: усреднение с учетом размера классов

## 2. Методы решения задачи классификации. Метод k ближайших соседей (kNN). Метод опорных векторов. Деревья решений. Комитетные методы, стратегии построения обучающего множества. Леса (джунгли). Bagging. Boosting.

### Метод k ближайших соседей (kNN)

**Принцип работы:**
1. Для нового объекта находится k ближайших объектов из обучающей выборки
2. Класс определяется голосованием большинства среди k соседей
3. Расстояние вычисляется по метрике (обычно евклидово расстояние)

**Параметры:**
- **k**: количество соседей (нечетное число для избежания ничьих)
- **Метрика расстояния**: евклидово, манхэттенское, косинусное

**Преимущества:**
- Простота реализации
- Не требует обучения
- Хорошо работает на нелинейных данных

**Недостатки:**
- Медленный на больших данных
- Чувствителен к масштабу признаков
- Чувствителен к выбросам

### Метод опорных векторов (SVM)

**Принцип работы:**
- Ищет оптимальную разделяющую гиперплоскость с максимальным зазором между классами
- Опорные векторы — объекты, лежащие на границе зазора
- Использует ядерные функции для работы с нелинейными данными

**Ядерные функции:**
- Линейное: $K(x_i, x_j) = x_i^T x_j$
- Полиномиальное: $K(x_i, x_j) = (x_i^T x_j + 1)^d$
- RBF (радиально-базисная): $K(x_i, x_j) = \exp(-\gamma ||x_i - x_j||^2)$

**Преимущества:**
- Эффективен на малых выборках
- Работает с нелинейными данными через ядра
- Устойчив к переобучению

**Недостатки:**
- Медленный на больших данных
- Требует тщательной настройки параметров

### Деревья решений

**Принцип работы:**
- Рекурсивное разбиение пространства признаков по правилам вида "если признак < порог, то..."
- Критерии разбиения: энтропия, индекс Джини, ошибка классификации
- Остановка при достижении листьев (чистые узлы или ограничение глубины)

**Алгоритм построения:**
1. Выбор признака и порога для разбиения (минимизация неоднородности)
2. Рекурсивное применение к подмножествам
3. Присвоение класса листьям

**Преимущества:**
- Интерпретируемость
- Работа с категориальными признаками
- Устойчивость к выбросам

**Недостатки:**
- Склонность к переобучению
- Нестабильность (малые изменения данных меняют дерево)

### Комитетные методы (ансамбли)

**Идея:** объединение нескольких моделей для улучшения качества предсказаний.

### Bagging (Bootstrap Aggregating)

**Принцип:**
1. Создание множества бутстрап-выборок из исходных данных
2. Обучение отдельной модели на каждой выборке
3. Агрегация предсказаний (голосование для классификации, усреднение для регрессии)

**Примеры:**
- **Random Forest**: ансамбль деревьев решений с дополнительной случайностью (случайный выбор признаков)

**Преимущества:**
- Снижение дисперсии
- Устойчивость к переобучению
- Параллелизация обучения

### Boosting

**Принцип:**
1. Последовательное обучение моделей
2. Каждая следующая модель фокусируется на ошибках предыдущих
3. Взвешенное голосование моделей

**Алгоритмы:**
- **AdaBoost**: адаптивное повышение весов неправильно классифицированных объектов
- **Gradient Boosting**: минимизация функции потерь градиентным спуском
- **XGBoost, LightGBM**: оптимизированные версии градиентного бустинга

**Преимущества:**
- Высокая точность
- Снижение смещения

**Недостатки:**
- Склонность к переобучению
- Последовательное обучение (медленнее)

### Леса (джунгли)

**Random Forest (Случайный лес)** — частный случай bagging для деревьев:
- Каждое дерево обучается на бутстрап-выборке
- При разбиении узла выбирается случайное подмножество признаков
- Финальное предсказание — голосование всех деревьев

## 3. Нейронная сеть в задаче распознавания: типы, структура, виды активационных функций, методы обучения. Метод обратного распространения ошибки.

### Типы нейронных сетей

**1. Полносвязные сети (Fully Connected / Dense)**
- Каждый нейрон связан со всеми нейронами следующего слоя
- Применение: базовые задачи классификации

**2. Сверточные нейронные сети (CNN)**
- Используют сверточные слои для работы с изображениями
- Применение: распознавание изображений, компьютерное зрение

**3. Рекуррентные нейронные сети (RNN)**
- Имеют обратные связи для работы с последовательностями
- Применение: обработка текста, временные ряды

**4. Долгосрочная краткосрочная память (LSTM)**
- Специальный тип RNN с механизмом памяти
- Применение: долгосрочные зависимости в последовательностях

### Структура нейронной сети

**Основные компоненты:**
1. **Входной слой**: принимает признаки объекта
2. **Скрытые слои**: промежуточные слои для извлечения признаков
3. **Выходной слой**: выдает предсказание (вероятности классов)

**Архитектура:**
- **Feedforward**: информация движется только вперед
- **Глубина**: количество скрытых слоев
- **Ширина**: количество нейронов в слое

### Виды активационных функций

Активационная функция определяет выход нейрона на основе взвешенной суммы входов.

#### 1. Sigmoid (Логистическая функция)

**Формула:** $\sigma(x) = \frac{1}{1 + e^{-x}}$

**Характеристики:**
- Диапазон значений: (0, 1)
- S-образная кривая
- Дифференцируема везде

**Применение:**
- Выходной слой для бинарной классификации (вероятность)
- Исторически использовалась в скрытых слоях

**Преимущества:**
- Ограниченный выход (удобно для вероятностей)
- Гладкая функция

**Недостатки:**
- **Проблема исчезающих градиентов**: производная мала при больших |x|, градиенты затухают
- Несимметрична относительно нуля
- Вычислительно дорогая (экспонента)

#### 2. Tanh (Гиперболический тангенс)

**Формула:** $\tanh(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}} = \frac{2}{1 + e^{-2x}} - 1$

**Характеристики:**
- Диапазон значений: (-1, 1)
- S-образная кривая, симметрична относительно нуля
- Дифференцируема везде

**Применение:**
- Скрытые слои (предпочтительнее sigmoid из-за симметричности)

**Преимущества:**
- Симметричность относительно нуля (среднее значение близко к 0)
- Более сильные градиенты, чем у sigmoid

**Недостатки:**
- Все еще проблема исчезающих градиентов
- Вычислительно дорогая

#### 3. ReLU (Rectified Linear Unit)

**Формула:** $ReLU(x) = \max(0, x) = \begin{cases} x, & \text{если } x > 0 \\ 0, & \text{если } x \leq 0 \end{cases}$

**Характеристики:**
- Линейна для положительных значений, равна 0 для отрицательных
- Недифференцируема в точке 0 (на практике используют производную = 0 или 1)

**Применение:**
- **Стандартный выбор для скрытых слоев** в большинстве современных сетей

**Преимущества:**
- **Решает проблему исчезающих градиентов** для положительных значений (производная = 1)
- Вычислительно эффективна (простое сравнение)
- Ускоряет сходимость обучения
- Создает разреженные представления (многие нейроны = 0)

**Недостатки:**
- **Проблема "умирающих ReLU"**: если нейрон всегда выдает отрицательные значения, градиент = 0, нейрон "умирает"
- Недифференцируема в 0 (не критично на практике)

#### 4. Leaky ReLU

**Формула:** $LeakyReLU(x) = \max(\alpha x, x)$, где $\alpha$ — малый коэффициент (обычно 0.01)

**Характеристики:**
- Аналогична ReLU, но для отрицательных значений возвращает $\alpha x$ вместо 0

**Применение:**
- Альтернатива ReLU для предотвращения "умирающих нейронов"

**Преимущества:**
- Решает проблему "умирающих ReLU"
- Сохраняет преимущества ReLU

**Недостатки:**
- Требует настройки параметра $\alpha$

#### 5. ELU (Exponential Linear Unit)

**Формула:** $ELU(x) = \begin{cases} x, & \text{если } x > 0 \\ \alpha(e^x - 1), & \text{если } x \leq 0 \end{cases}$

**Характеристики:**
- Плавная функция для отрицательных значений
- Параметр $\alpha$ обычно равен 1

**Применение:**
- Когда нужны более плавные переходы, чем у ReLU

**Преимущества:**
- Плавная функция (лучше для оптимизации)
- Решает проблему "умирающих ReLU"
- Близка к нулевому среднему (ускоряет обучение)

**Недостатки:**
- Вычислительно дороже ReLU (экспонента)

#### 6. Softmax

**Формула:** $softmax(x_i) = \frac{e^{x_i}}{\sum_{j=1}^{n} e^{x_j}}$

**Характеристики:**
- Преобразует вектор в распределение вероятностей
- Сумма выходов = 1
- Все выходы > 0

**Применение:**
- **Только для выходного слоя** в многоклассовой классификации
- Преобразует логиты в вероятности классов

**Преимущества:**
- Естественная интерпретация как вероятности
- Дифференцируема

**Недостатки:**
- Только для выходного слоя
- Чувствительна к большим значениям (может вызвать переполнение)

### Методы обучения нейронных сетей

**1. Градиентный спуск (Gradient Descent)**
- Минимизация функции потерь путем движения в направлении антиградиента
- Обновление весов: $w_{new} = w_{old} - \alpha \nabla L$, где $\alpha$ — скорость обучения

**Варианты:**
- **Batch GD**: использование всей выборки
- **Stochastic GD**: один объект за раз
- **Mini-batch GD**: небольшие батчи (стандартный подход)

**2. Оптимизаторы:**
- **Momentum**: учет предыдущих градиентов для сглаживания
- **Adam**: адаптивная скорость обучения для каждого параметра
- **RMSprop**: адаптивная скорость обучения на основе скользящего среднего квадратов градиентов

### Метод обратного распространения ошибки (Backpropagation)

**Принцип работы:**

1. **Прямой проход (Forward Pass):**
   - Входные данные проходят через сеть
   - Вычисляется выход и функция потерь

2. **Обратный проход (Backward Pass):**
   - Вычисление градиентов функции потерь по весам
   - Использование правила цепочки (chain rule) для распространения ошибки назад

**Алгоритм:**

1. Вычислить ошибку на выходном слое: $\delta^{(L)} = \frac{\partial L}{\partial a^{(L)}} \cdot f'(z^{(L)})$

2. Распространить ошибку назад по слоям:
   $$\delta^{(l)} = ((W^{(l+1)})^T \delta^{(l+1)}) \odot f'(z^{(l)})$$
   где $\odot$ — поэлементное умножение

3. Вычислить градиенты весов:
   $$\frac{\partial L}{\partial W^{(l)}} = \delta^{(l)} (a^{(l-1)})^T$$

4. Обновить веса:
   $$W^{(l)} = W^{(l)} - \alpha \frac{\partial L}{\partial W^{(l)}}$$

**Ключевые моменты:**
- Использует правило цепочки для вычисления производных сложной функции
- Эффективно вычисляет градиенты для всех весов за один проход
- Требует дифференцируемости активационных функций

## 4. Дискриминантный анализ. Дискриминантная функция.

### Дискриминантный анализ

**Дискриминантный анализ** — статистический метод классификации, основанный на построении линейных или квадратичных разделяющих функций.

**Основные предположения:**
1. Нормальное распределение признаков в каждом классе
2. Равенство ковариационных матриц классов (для линейного дискриминантного анализа)
3. Отсутствие мультиколлинеарности признаков

### Линейный дискриминантный анализ (LDA)

**Идея:** найти линейную комбинацию признаков, которая максимизирует разделимость классов.

**Дискриминантная функция для класса $k$:**
$$\delta_k(x) = x^T \Sigma^{-1} \mu_k - \frac{1}{2} \mu_k^T \Sigma^{-1} \mu_k + \log(\pi_k)$$

где:
- $\mu_k$ — средний вектор класса $k$
- $\Sigma$ — общая ковариационная матрица (предполагается одинаковой для всех классов)
- $\pi_k$ — априорная вероятность класса $k$

**Правило классификации:**
- Объект $x$ относится к классу $k$, если $\delta_k(x) > \delta_j(x)$ для всех $j \neq k$

### Квадратичный дискриминантный анализ (QDA)

**Отличие от LDA:** допускает различные ковариационные матрицы для классов.

**Дискриминантная функция:**
$$\delta_k(x) = -\frac{1}{2} \log|\Sigma_k| - \frac{1}{2}(x - \mu_k)^T \Sigma_k^{-1}(x - \mu_k) + \log(\pi_k)$$

**Применение:**
- Когда классы имеют различную форму распределения
- Более гибкий, но требует больше параметров

### Преимущества и недостатки

**Преимущества:**
- Простота интерпретации
- Быстрое обучение и предсказание
- Эффективен при малом объеме данных
- Может использоваться для снижения размерности

**Недостатки:**
- Строгие предположения о распределении данных
- Чувствителен к выбросам
- Требует отсутствия мультиколлинеарности

## 5. Процедура применения алгоритма (метод опорных векторов, дискриминантная функция, метод k-ближайших соседей, дерево решений).

### Метод опорных векторов (SVM)

**Процедура:**

1. **Подготовка данных:**
   - Нормализация признаков (критично для SVM)
   - Разделение на обучающую и тестовую выборки

2. **Выбор параметров:**
   - Тип ядра (linear, polynomial, RBF)
   - Параметр регуляризации $C$
   - Параметры ядра (например, $\gamma$ для RBF)

3. **Обучение:**
   - Решение задачи оптимизации для нахождения разделяющей гиперплоскости
   - Определение опорных векторов

4. **Предсказание:**
   - Вычисление расстояния до разделяющей гиперплоскости
   - Присвоение класса на основе знака расстояния

### Дискриминантная функция (LDA/QDA)

**Процедура:**

1. **Проверка предположений:**
   - Нормальность распределения признаков
   - Проверка равенства ковариационных матриц (для LDA)

2. **Обучение:**
   - Вычисление средних векторов классов: $\mu_k = \frac{1}{n_k} \sum_{i: y_i=k} x_i$
   - Вычисление ковариационных матриц
   - Вычисление априорных вероятностей: $\pi_k = \frac{n_k}{n}$

3. **Предсказание:**
   - Вычисление дискриминантных функций для всех классов
   - Выбор класса с максимальным значением функции

### Метод k-ближайших соседей (kNN)

**Процедура:**

1. **Подготовка данных:**
   - Нормализация признаков (критично!)
   - Выбор метрики расстояния

2. **Выбор параметра k:**
   - Обычно нечетное число
   - Подбор на валидационной выборке

3. **Предсказание для нового объекта:**
   - Вычисление расстояний до всех объектов обучающей выборки
   - Выбор k ближайших объектов
   - Голосование большинством (или взвешенное голосование)

### Дерево решений

**Процедура:**

1. **Выбор критерия разбиения:**
   - Энтропия: $H(S) = -\sum_{i} p_i \log_2(p_i)$
   - Индекс Джини: $Gini(S) = 1 - \sum_{i} p_i^2$
   - Ошибка классификации: $Error(S) = 1 - \max(p_i)$

2. **Построение дерева:**
   - Для каждого узла:
     - Выбор признака и порога, максимизирующих информационный прирост
     - Разбиение данных по выбранному правилу
     - Рекурсивное применение к подмножествам
   - Остановка при достижении критерия (чистый узел, максимальная глубина, минимальное количество объектов)

3. **Предсказание:**
   - Прохождение объекта по дереву от корня к листу
   - Присвоение класса, соответствующего листу

## 6. Метрики качества классификации. Доля правильно распознанных ответов, точность, полнота и др. PR-, ROC-кривая. Оценка качества многоклассовой классификации.

### Основные метрики

**Confusion Matrix (Матрица ошибок):**

|                | Предсказано: Положительный | Предсказано: Отрицательный |
|----------------|---------------------------|---------------------------|
| Реально: Положительный | TP (True Positive)      | FN (False Negative)       |
| Реально: Отрицательный | FP (False Positive)      | TN (True Negative)        |

**Базовые метрики:**

1. **Accuracy (Точность/Доля правильно распознанных):**
   $$Accuracy = \frac{TP + TN}{TP + TN + FP + FN}$$
   - Доля всех правильно классифицированных объектов
   - Может быть вводящей в заблуждение при дисбалансе классов

2. **Precision (Точность/Прецизионность):**
   $$Precision = \frac{TP}{TP + FP}$$
   - Доля объектов, предсказанных как положительные, которые действительно положительные
   - "Из всех предсказанных положительных, сколько правильных?"

3. **Recall (Полнота/Чувствительность):**
   $$Recall = \frac{TP}{TP + FN}$$
   - Доля положительных объектов, которые были правильно идентифицированы
   - "Из всех реальных положительных, сколько найдено?"

4. **Specificity (Специфичность):**
   $$Specificity = \frac{TN}{TN + FP}$$
   - Доля отрицательных объектов, которые были правильно идентифицированы

5. **F-мера (F1-score):**
   $$F_1 = 2 \cdot \frac{Precision \cdot Recall}{Precision + Recall}$$
   - Гармоническое среднее precision и recall
   - Балансирует между точностью и полнотой

6. **F-бета мера:**
   $$F_\beta = (1 + \beta^2) \cdot \frac{Precision \cdot Recall}{\beta^2 \cdot Precision + Recall}$$
   - $\beta > 1$: больше вес recall
   - $\beta < 1$: больше вес precision

### ROC-кривая (Receiver Operating Characteristic)

**Определение:**
- График зависимости True Positive Rate (TPR = Recall) от False Positive Rate (FPR = 1 - Specificity)
- Строится при изменении порога классификации

**Характеристики:**
- **TPR (Sensitivity)**: $\frac{TP}{TP + FN}$
- **FPR**: $\frac{FP}{FP + TN}$

**AUC-ROC (Area Under Curve):**
- Площадь под ROC-кривой
- Диапазон: [0, 1]
- **Интерпретация:**
  - 1.0 — идеальный классификатор
  - 0.5 — случайное угадывание
  - > 0.7 — хороший классификатор
  - > 0.9 — отличный классификатор

**Применение:**
- Оценка качества при различных порогах
- Сравнение моделей независимо от порога
- Хорошо работает при сбалансированных классах

### PR-кривая (Precision-Recall)

**Определение:**
- График зависимости Precision от Recall при изменении порога

**Применение:**
- Предпочтительна при **дисбалансе классов**
- Более информативна, чем ROC, когда отрицательных объектов много

**AUC-PR:**
- Площадь под PR-кривой
- Более строгая метрика, чем AUC-ROC

### Многоклассовая классификация

**Стратегии оценки:**

1. **Macro-averaging:**
   - Вычисление метрики для каждого класса отдельно
   - Усреднение по всем классам
   - Каждый класс имеет равный вес
   - $$Macro-Precision = \frac{1}{C} \sum_{i=1}^{C} Precision_i$$

2. **Micro-averaging:**
   - Агрегация всех TP, FP, TN, FN по всем классам
   - Вычисление метрики на агрегированных значениях
   - Учитывает размер классов
   - $$Micro-Precision = \frac{\sum_{i=1}^{C} TP_i}{\sum_{i=1}^{C} TP_i + \sum_{i=1}^{C} FP_i}$$

3. **Weighted-averaging:**
   - Усреднение с весами, пропорциональными размеру классов
   - $$Weighted-Precision = \sum_{i=1}^{C} w_i \cdot Precision_i$$
   где $w_i = \frac{n_i}{n}$

**Пример для 3 классов:**

| Класс | TP | FP | TN | FN | Precision | Recall |
|-------|----|----|----|----|-----------|--------|
| A     | 10 | 2  | 15 | 3  | 0.83      | 0.77   |
| B     | 8  | 1  | 18 | 3  | 0.89      | 0.73   |
| C     | 12 | 3  | 12 | 3  | 0.80      | 0.80   |

- **Macro-Precision**: (0.83 + 0.89 + 0.80) / 3 = 0.84
- **Micro-Precision**: (10 + 8 + 12) / (10 + 8 + 12 + 2 + 1 + 3) = 30 / 34 = 0.88

## 7. Заполнить confusion matrix, рассчитать метрики (accuracy, precision, recall, F-меру и др.).

### Заполнение Confusion Matrix

**Пример задачи:**

Дано:
- Всего объектов: 100
- Реально положительных: 60
- Реально отрицательных: 40
- Предсказано положительных: 55
- Предсказано отрицательных: 45
- Правильно классифицированных: 85

**Решение:**

1. **Находим TP и TN:**
   - Правильно классифицированных: 85
   - Нужно определить распределение между TP и TN

2. **Используем дополнительные данные:**
   - Если известно, что TP = 50, FP = 5, FN = 10, TN = 35
   - Проверка: TP + FP = 55 ✓, TP + FN = 60 ✓, TN + FP = 40 ✓, TN + FN = 45 ✓

**Confusion Matrix:**

|                | Предсказано: + | Предсказано: - | Всего |
|----------------|---------------|---------------|-------|
| Реально: +     | 50 (TP)       | 10 (FN)       | 60    |
| Реально: -     | 5 (FP)        | 35 (TN)       | 40    |
| Всего          | 55            | 45            | 100   |

### Расчет метрик

**1. Accuracy (Точность):**
$$Accuracy = \frac{TP + TN}{TP + TN + FP + FN} = \frac{50 + 35}{100} = \frac{85}{100} = 0.85 = 85\%$$

**2. Precision (Прецизионность):**
$$Precision = \frac{TP}{TP + FP} = \frac{50}{50 + 5} = \frac{50}{55} = 0.909 = 90.9\%$$

**3. Recall (Полнота):**
$$Recall = \frac{TP}{TP + FN} = \frac{50}{50 + 10} = \frac{50}{60} = 0.833 = 83.3\%$$

**4. Specificity (Специфичность):**
$$Specificity = \frac{TN}{TN + FP} = \frac{35}{35 + 5} = \frac{35}{40} = 0.875 = 87.5\%$$

**5. F1-мера:**
$$F_1 = 2 \cdot \frac{Precision \cdot Recall}{Precision + Recall} = 2 \cdot \frac{0.909 \cdot 0.833}{0.909 + 0.833} = 2 \cdot \frac{0.757}{1.742} = 0.869 = 86.9\%$$

**6. FPR (False Positive Rate):**
$$FPR = \frac{FP}{FP + TN} = \frac{5}{5 + 35} = \frac{5}{40} = 0.125 = 12.5\%$$

**7. FNR (False Negative Rate):**
$$FNR = \frac{FN}{FN + TP} = \frac{10}{10 + 50} = \frac{10}{60} = 0.167 = 16.7\%$$

### Интерпретация результатов

- **Accuracy 85%**: 85 из 100 объектов классифицированы правильно
- **Precision 90.9%**: Из 55 предсказанных положительных, 50 действительно положительные (5 ложных срабатываний)
- **Recall 83.3%**: Из 60 реальных положительных, найдено 50 (10 пропущено)
- **F1 86.9%**: Баланс между точностью и полнотой

**Рекомендации:**
- Если важнее минимизировать ложные срабатывания → фокус на Precision
- Если важнее найти все положительные случаи → фокус на Recall
- Если нужен баланс → используем F1-меру

## 9. Алгоритм построения дерева решений. Для представленного массива построить фрагмент дерева решений. Рассчитать индекс неоднородности для узлов дерева. Оценить по индексу неоднородности качество дерева.

### Алгоритм построения дерева решений

**Основные шаги:**

1. **Начало:** Корневой узел содержит всю обучающую выборку

2. **Выбор признака для разбиения:**
   - Для каждого признака и каждого возможного порога:
     - Вычисляется информационный прирост (Information Gain)
     - Выбирается признак и порог с максимальным приростом

3. **Информационный прирост:**
   $$IG(S, A) = H(S) - \sum_{v \in Values(A)} \frac{|S_v|}{|S|} H(S_v)$$
   где:
   - $H(S)$ — энтропия исходного множества
   - $A$ — признак для разбиения
   - $S_v$ — подмножество с значением $v$ признака $A$

4. **Разбиение:**
   - Создание дочерних узлов для каждого значения/диапазона признака

5. **Рекурсия:**
   - Применение алгоритма к каждому дочернему узлу

6. **Критерии остановки:**
   - Все объекты в узле принадлежат одному классу (чистый узел)
   - Достигнута максимальная глубина
   - Минимальное количество объектов в узле
   - Информационный прирост меньше порога

### Индексы неоднородности

**1. Энтропия (Entropy):**
$$H(S) = -\sum_{i=1}^{c} p_i \log_2(p_i)$$
где $p_i$ — доля объектов класса $i$ в множестве $S$

**Характеристики:**
- Диапазон: [0, 1] (для бинарной классификации)
- 0 — все объекты одного класса (чистый узел)
- 1 — равномерное распределение классов (максимальная неоднородность)

**2. Индекс Джини (Gini Index):**
$$Gini(S) = 1 - \sum_{i=1}^{c} p_i^2$$

**Характеристики:**
- Диапазон: [0, 0.5] (для бинарной классификации)
- 0 — чистый узел
- 0.5 — максимальная неоднородность

**3. Ошибка классификации (Classification Error):**
$$Error(S) = 1 - \max(p_i)$$

**Характеристики:**
- Диапазон: [0, 0.5] (для бинарной классификации)
- Менее чувствительна, чем энтропия и Джини

### Пример построения дерева

**Данные:**

| Возраст | Доход | Класс |
|---------|-------|-------|
| Молодой | Низкий | Нет   |
| Молодой | Высокий | Да    |
| Средний | Низкий | Нет   |
| Средний | Высокий | Да    |
| Старый  | Низкий | Нет   |
| Старый  | Средний | Нет   |
| Старый  | Высокий | Да    |

**Шаг 1: Вычисление энтропии корневого узла**

Всего объектов: 7
- Класс "Да": 3
- Класс "Нет": 4

$$H(S) = -\frac{3}{7}\log_2(\frac{3}{7}) - \frac{4}{7}\log_2(\frac{4}{7}) = -0.429 \cdot (-1.22) - 0.571 \cdot (-0.81) = 0.985$$

**Шаг 2: Разбиение по признаку "Возраст"**

**Молодой (2 объекта):**
- Да: 1, Нет: 1
$$H(Молодой) = -\frac{1}{2}\log_2(\frac{1}{2}) - \frac{1}{2}\log_2(\frac{1}{2}) = 1.0$$

**Средний (2 объекта):**
- Да: 1, Нет: 1
$$H(Средний) = 1.0$$

**Старый (3 объекта):**
- Да: 1, Нет: 2
$$H(Старый) = -\frac{1}{3}\log_2(\frac{1}{3}) - \frac{2}{3}\log_2(\frac{2}{3}) = 0.918$$

**Информационный прирост:**
$$IG(S, Возраст) = 0.985 - \frac{2}{7} \cdot 1.0 - \frac{2}{7} \cdot 1.0 - \frac{3}{7} \cdot 0.918 = 0.985 - 0.966 = 0.019$$

**Шаг 3: Разбиение по признаку "Доход"**

**Низкий (3 объекта):**
- Да: 0, Нет: 3
$$H(Низкий) = 0$$ (чистый узел!)

**Средний (1 объект):**
- Да: 0, Нет: 1
$$H(Средний) = 0$$

**Высокий (3 объекта):**
- Да: 3, Нет: 0
$$H(Высокий) = 0$$ (чистый узел!)

**Информационный прирост:**
$$IG(S, Доход) = 0.985 - \frac{3}{7} \cdot 0 - \frac{1}{7} \cdot 0 - \frac{3}{7} \cdot 0 = 0.985$$

**Вывод:** Признак "Доход" дает больший информационный прирост → выбираем его для разбиения.

**Фрагмент дерева:**

```
                    [Корень: H=0.985]
                            |
                    Разбиение по Доходу
                            |
            +---------------+---------------+---------------+
            |               |               |               |
      [Низкий]         [Средний]      [Высокий]
      H=0.0            H=0.0          H=0.0
      Класс: Нет       Класс: Нет     Класс: Да
```

### Оценка качества дерева по индексу неоднородности

**Критерии качества:**

1. **Низкая неоднородность в листьях:**
   - Листья должны быть максимально чистыми (H ≈ 0 или Gini ≈ 0)
   - Высокая неоднородность в листьях → плохое качество

2. **Уменьшение неоднородности при разбиении:**
   - Каждое разбиение должно значительно снижать неоднородность
   - Большой информационный прирост → хорошее разбиение

3. **Баланс между глубиной и чистотой:**
   - Слишком глубокое дерево → переобучение
   - Слишком мелкое дерево → недообучение

**В нашем примере:**
- Корневой узел: H = 0.985 (высокая неоднородность)
- После разбиения по "Доходу": все листья имеют H = 0 (идеальная чистота)
- **Оценка: ОТЛИЧНОЕ дерево** — полное разделение классов за одно разбиение

## 10. Оценка значимости признаков

### Методы оценки значимости признаков

**1. Коэффициенты модели (Логистическая регрессия, LDA, SVM)**

**Принцип:**
- Абсолютное значение коэффициента пропорционально влиянию признака на предсказание
- Положительный коэффициент: увеличение признака увеличивает вероятность положительного класса
- Отрицательный коэффициент: обратная связь

**Пример:**
- Признак A: коэффициент = 2.5
- Признак B: коэффициент = -1.8
- Признак C: коэффициент = 0.3

**Интерпретация:**
- Признак A наиболее важен (|2.5|)
- Признак B важен, но с обратной связью
- Признак C слабо влияет

**2. Feature Importance (Деревья решений, Random Forest)**

**Принцип:**
- Основано на уменьшении неоднородности (Gini или энтропии) при использовании признака
- Для Random Forest: усреднение по всем деревьям

**Формула (Gini Importance):**
$$Importance_j = \sum_{nodes \ using \ feature \ j} \Delta Gini \cdot \frac{n_{node}}{n_{total}}$$

где $\Delta Gini$ — уменьшение индекса Джини при разбиении узла

**Пример:**
- Признак "Доход": важность = 0.45
- Признак "Возраст": важность = 0.30
- Признак "Образование": важность = 0.25

**3. Permutation Importance**

**Принцип:**
1. Обучение модели на исходных данных
2. Оценка качества модели (например, accuracy)
3. Перемешивание значений признака
4. Повторная оценка качества
5. Падение качества = важность признака

**Преимущества:**
- Не зависит от типа модели
- Учитывает взаимодействия признаков
- Более надежен, чем коэффициенты

**4. SHAP (SHapley Additive exPlanations) Values**

**Принцип:**
- Основано на теории игр
- Вычисляет вклад каждого признака в предсказание для каждого объекта
- Среднее абсолютное значение SHAP = важность признака

**Преимущества:**
- Универсальный метод
- Учитывает взаимодействия
- Интерпретируемость на уровне отдельных предсказаний

### Практический пример оценки

**Результаты Random Forest:**

| Признак | Важность | Нормализованная важность |
|---------|----------|-------------------------|
| Признак A | 0.35 | 35% |
| Признак B | 0.28 | 28% |
| Признак C | 0.22 | 22% |
| Признак D | 0.15 | 15% |

**Интерпретация:**
- Признак A критически важен (35% вклада)
- Признаки A, B, C вместе дают 85% важности
- Признак D имеет низкую значимость

**Рекомендации:**
- Фокус на признаках A, B, C при сборе данных
- Можно рассмотреть удаление признака D для упрощения модели
- Признак A должен быть наиболее качественным и полным

### Визуализация значимости

**Методы:**
1. **Bar plot**: столбчатая диаграмма важности признаков
2. **Feature importance plot**: встроенные функции библиотек (sklearn, xgboost)
3. **SHAP summary plot**: визуализация SHAP значений

**Использование:**
- Выбор наиболее информативных признаков
- Упрощение модели (feature selection)
- Понимание того, на что модель обращает внимание
- Обнаружение проблем (например, модель полагается на нерелевантный признак)
