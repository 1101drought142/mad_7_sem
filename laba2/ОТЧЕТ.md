## 6. Описание параметров методов

### 6.1. Нейронная сеть (MLPClassifier)

#### 6.1.1. Структура нейросети

```
Архитектура:
Входной слой: 4 нейрона (4 признака)
    ↓
Скрытый слой 1: 100 нейронов (ReLU активация)
    ↓
Скрытый слой 2: 50 нейронов (ReLU активация)
    ↓
Выходной слой: 3 нейрона (softmax активация для классификации)
```

**Общее количество параметров:**
- Вход → Скрытый 1: 4 × 100 + 100 (bias) = 500
- Скрытый 1 → Скрытый 2: 100 × 50 + 50 (bias) = 5,050
- Скрытый 2 → Выход: 50 × 3 + 3 (bias) = 153
- **Итого:** ~5,703 параметра

#### 6.1.2. Параметры обучения

| Параметр | Значение | Обоснование |
|----------|----------|-------------|
| `hidden_layer_sizes` | (100, 50) | Достаточно для нелинейной классификации, но не переобучается |
| `activation` | 'relu' | ReLU лучше работает для глубоких сетей, чем sigmoid/tanh |
| `solver` | 'adam' | Адаптивный оптимизатор, быстрее и эффективнее SGD |
| `alpha` | 0.001 | L2 регуляризация предотвращает переобучение |
| `learning_rate` | 'adaptive' | Автоматически уменьшает скорость при отсутствии улучшений |
| `learning_rate_init` | 0.001 | Начальная скорость обучения (стандартное значение) |
| `max_iter` | 1000 | Максимальное количество итераций |
| `early_stopping` | True | Остановка при отсутствии улучшений на валидации |
| `validation_fraction` | 0.1 | 10% данных для валидации |
| `n_iter_no_change` | 10 | Количество итераций без улучшения для остановки |

**Обоснование выбора:**
- Два скрытых слоя обеспечивают достаточную нелинейность для разделения классов
- ReLU активация ускоряет обучение и решает проблему затухающих градиентов
- Adam оптимизатор адаптирует скорость обучения для каждого параметра
- Early stopping предотвращает переобучение

### 6.2. Метод опорных векторов (SVM)

#### 6.2.1. Параметры модели

| Параметр | Значение | Обоснование |
|----------|----------|-------------|
| `kernel` | 'rbf' | Радиальная базисная функция для нелинейной классификации |
| `C` | 1.0 | Баланс между переобучением и недообучением |
| `gamma` | 'scale' | Автоматический выбор: 1 / (n_features × X.var()) |
| `probability` | True | Включено для расчета вероятностей (нужно для AUC) |

#### 6.2.2. Обоснование выбора параметров

**RBF ядро:**
- Классы versicolor и virginica не линейно разделимы (видно на scatter plots)
- RBF ядро позволяет строить нелинейные границы решения
- Формула: `K(x, x') = exp(-γ||x - x'||²)`

**Параметр C:**
- C = 1.0 - стандартное значение, балансирует между:
  - Малый C: более "мягкая" граница, больше допускает ошибки
  - Большой C: более "жесткая" граница, меньше допускает ошибки

**Параметр gamma:**
- gamma='scale' автоматически выбирает оптимальное значение
- Контролирует "радиус влияния" опорных векторов:
  - Малый gamma: широкое влияние, более плавная граница
  - Большой gamma: узкое влияние, более сложная граница
