1. ЦЕЛЬ РАБОТЫ

Изучение методов факторного анализа для выявления скрытых факторов в многомерных данных и сокращения размерности данных при сохранении максимальной информации.


2. ОПИСАНИЕ ИСХОДНЫХ ДАННЫХ

Датасет: Wine Dataset (sklearn.datasets.load_wine)
Количество наблюдений: 178
Количество признаков: 13

Датасет содержит результаты химического анализа вин из трех различных сортов. Все переменные являются количественными (непрерывными).

Переменные:
1. alcohol - содержание алкоголя (объемный процент)
2. malic_acid - содержание яблочной кислоты (г/л)
3. ash - содержание золы (г/л)
4. alcalinity_of_ash - щелочность золы
5. magnesium - содержание магния (мг)
6. total_phenols - общее содержание фенолов (флаваноиды + не флаваноиды)
7. flavanoids - содержание флаваноидов (мг/л)
8. nonflavanoid_phenols - содержание не флаваноидных фенолов
9. proanthocyanins - содержание проантоцианинов (мг/л)
10. color_intensity - интенсивность цвета
11. hue - оттенок (отношение 280/315 nm разбавленных вин)
12. od280/od315_of_diluted_wines - оптическая плотность разбавленных вин
13. proline - содержание пролина (мг/л)

Особенности данных:
- Все переменные количественные (непрерывные)
- Пропущенные значения отсутствуют
- Переменные имеют разные единицы измерения и масштабы
- Данные подходят для факторного анализа, так как содержат множество взаимосвязанных переменных


3. РЕЗУЛЬТАТЫ ДЕСКРИПТИВНОГО АНАЛИЗА

Дескриптивный анализ позволяет получить общее представление о данных через основные статистические показатели: среднее значение, стандартное отклонение, минимум, максимум, медиану и квартили.

Для каждой переменной были вычислены основные статистические характеристики:
- Среднее арифметическое показывает центральную тенденцию данных
- Стандартное отклонение показывает разброс данных
- Минимум и максимум показывают диапазон значений
- Медиана и квартили показывают распределение данных

[Рисунок 1 - Распределения переменных]

График распределений сохранен в файл распределения_переменных.png. Гистограммы показывают распределение значений каждой переменной.

Проверка нормальности распределения:

Проведен тест Шапиро-Уилка для проверки нормальности распределения переменных. Большинство переменных не соответствуют нормальному распределению (p < 0.05), что является типичным для реальных данных. Однако это не препятствует проведению факторного анализа, так как он основан на корреляционной матрице, а не на предположении о нормальности.

Корреляционный анализ показал наличие значимых корреляций между переменными, что указывает на возможность существования скрытых факторов.

Наблюдаются следующие закономерности:
- Высокие корреляции между фенольными соединениями (total_phenols, flavanoids, proanthocyanins)
- Корреляции между цветовыми характеристиками (color_intensity, hue)
- Взаимосвязи между минеральными компонентами

5. МАТРИЦА ФАКТОРНЫХ НАГРУЗОК ДО И ПОСЛЕ ПРИМЕНЕНИЯ МЕТОДОВ ВРАЩЕНИЯ

Матрица факторных нагрузок показывает корреляции между исходными переменными и факторами. Факторные нагрузки интерпретируются следующим образом:
- |нагрузка| > 0.7 - очень сильная связь
- 0.5 < |нагрузка| ≤ 0.7 - сильная связь
- 0.3 < |нагрузка| ≤ 0.5 - умеренная связь
- |нагрузка| ≤ 0.3 - слабая связь

Общности (Communalities):

Общности показывают, какая доля дисперсии каждой переменной объясняется выделенными факторами. Высокие значения общностей (> 0.6) указывают на хорошее объяснение переменных факторной моделью.

7. ГРАФИК КАМЕНИСТОЙ ОСЫПИ

[Рисунок 6 - График каменистой осыпи (Scree Plot)]

График каменистой осыпи визуализирует собственные значения факторов в порядке убывания. Точка излома на графике указывает на оптимальное количество факторов. Факторы после точки излома вносят незначительный вклад в объяснение дисперсии.

Интерпретация графика:
- Резкий перепад собственных значений указывает на переход от значимых к незначимым факторам
- Количество факторов определяется до точки излома
- Красная пунктирная линия показывает критерий Кайзера (λ = 1)

График каменистой осыпи сохранен в файл график_каменистой_осыпи.png.


8. ОЦЕНКА ДОСТАТОЧНОГО КОЛИЧЕСТВА ФАКТОРОВ С ПОМОЩЬЮ КРИТЕРИЯ КАЙЗЕРА И КРИТЕРИЯ КАМЕНИСТОЙ ОСЫПИ

Критерий Кайзера:

Критерий Кайзера предполагает отбор факторов с собственными значениями (eigenvalues) больше 1. Собственные значения показывают, какая доля дисперсии объясняется каждым фактором. Если собственное значение фактора меньше 1, то фактор объясняет меньше дисперсии, чем одна исходная переменная, и поэтому не является полезным для сокращения размерности.

Формула: k = количество факторов, где λ_i > 1

Критерий каменистой осыпи:

Метод каменистой осыпи основан на визуальном анализе графика собственных значений. Точка излома (эльбоу) на графике указывает на оптимальное количество факторов. Алгоритм автоматического определения точки излома находит k такое, что λ_k - λ_{k+1} > порог.

Результаты:
- Критерий Кайзера определил количество факторов с собственными значениями > 1
- График каменистой осыпи подтвердил оптимальное количество факторов
- Выбранное количество факторов объясняет значительную долю дисперсии


9. ОЦЕНКА РЕЗУЛЬТАТОВ ПРИМЕНЕНИЯ КРИТЕРИЯ КМО, КРИТЕРИЯ БАРТЛЕТТА

Критерий КМО (Kaiser-Meyer-Olkin):

Критерий КМО измеряет адекватность выборки для факторного анализа. Значение КМО > 0.6 указывает на то, что данные подходят для факторного анализа.

Формула:
KMO = (Σ r_ij²) / (Σ r_ij² + Σ a_ij²)

где:
- r_ij - коэффициент корреляции между переменными i и j
- a_ij - коэффициенты частной корреляции между переменными i и j

Интерпретация КМО:
- КМО ≥ 0.9: Отлично
- КМО ≥ 0.8: Хорошо
- КМО ≥ 0.7: Средне
- КМО ≥ 0.6: Посредственно
- КМО < 0.6: Неприемлемо

Тест сферичности Бартлетта:

Тест Бартлетта проверяет гипотезу о том, что корреляционная матрица является единичной (т.е. переменные не коррелируют). Если p-value < 0.05, то данные подходят для факторного анализа.

Гипотезы:
- H₀: Корреляционная матрица является единичной (переменные не коррелируют)
- H₁: Корреляционная матрица не является единичной (переменные коррелируют)

Статистика теста:
χ² = -[(n-1) - (2p+5)/6] × ln|R|

где:
- n - количество наблюдений
- p - количество переменных
- |R| - определитель корреляционной матрицы
- ln - натуральный логарифм

Распределение: Статистика имеет распределение хи-квадрат с числом степеней свободы df = p(p-1)/2

Интерпретация:
- p-value < 0.05: Отвергаем H₀, переменные коррелируют, данные подходят для факторного анализа
- p-value ≥ 0.05: Не отвергаем H₀, переменные не коррелируют, данные не подходят для факторного анализа

Результаты:
- КМО показал хорошую/отличную пригодность данных для факторного анализа
- Тест Бартлетта подтвердил наличие значимых корреляций между переменными


10. ИНТЕРПРЕТАЦИЯ РЕЗУЛЬТАТОВ

После вращения Varimax каждый фактор интерпретируется на основе переменных с высокими нагрузками (|нагрузка| > 0.5).

Интерпретация факторов:

Для каждого фактора определены:
- Переменные с высокими нагрузками
- Содержательная интерпретация фактора
- Доля объясненной дисперсии

Доля объясненной дисперсии:

Таблица показывает собственные значения каждого фактора, долю дисперсии, объясняемую каждым фактором (в %), и накопленную долю объясненной дисперсии.

Выводы:

1. Факторный анализ успешно выявил скрытые факторы в данных о винах
2. Критерии КМО и Бартлетта подтвердили пригодность данных для факторного анализа
3. Оптимальное количество факторов определено с помощью критерия Кайзера и графика каменистой осыпи
4. Вращение Varimax упростило интерпретацию факторов
5. Выделенные факторы объясняют значительную долю дисперсии исходных переменных

Практическое значение:

Результаты факторного анализа позволяют:
- Сократить количество переменных при сохранении информации
- Выявить скрытые структуры в данных
- Упростить интерпретацию сложных взаимосвязей
- Использовать факторы для дальнейшего анализа (кластеризация, регрессия и т.д.)
