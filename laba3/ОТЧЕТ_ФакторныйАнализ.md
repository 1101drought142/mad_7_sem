# ЛАБОРАТОРНАЯ РАБОТА ПО ФАКТОРНОМУ АНАЛИЗУ

## Цель работы
Изучение методов факторного анализа для выявления скрытых факторов в многомерных данных.

## 1. Описание исходных данных

### Датасет: Wine Dataset
- **Источник**: sklearn.datasets.load_wine
- **Количество наблюдений**: 178
- **Количество признаков**: 13

### Описание признаков:
1. **alcohol** - содержание алкоголя
2. **malic_acid** - содержание яблочной кислоты
3. **ash** - содержание золы
4. **alcalinity_of_ash** - щелочность золы
5. **magnesium** - содержание магния
6. **total_phenols** - общее содержание фенолов
7. **flavanoids** - содержание флавоноидов
8. **nonflavanoid_phenols** - содержание не флавоноидных фенолов
9. **proanthocyanins** - содержание проантоцианинов
10. **color_intensity** - интенсивность цвета
11. **hue** - оттенок
12. **od280/od315_of_diluted_wines** - оптическая плотность разбавленных вин
13. **proline** - содержание пролина

Данный датасет содержит результаты химического анализа различных вин и хорошо подходит для факторного анализа, так как содержит множество взаимосвязанных количественных переменных.

## 2. Результаты дескриптивного анализа

### Описательная статистика
Все переменные имеют разную шкалу измерения, что требует стандартизации перед проведением факторного анализа.

**Основные характеристики:**
- Пропущенные значения отсутствуют
- Все переменные являются количественными
- Разброс значений варьируется между переменными

### Проверка нормальности распределения

Проведен тест Шапиро-Уилка для проверки нормальности распределения переменных. Большинство переменных не соответствуют нормальному распределению (p < 0.05), что является типичным для реальных данных. Однако это не препятствует проведению факторного анализа, так как он основан на корреляционной матрице, а не на предположении о нормальности.

## 3. Корреляционный анализ

Корреляционный анализ показал наличие значимых корреляций между переменными, что указывает на возможность существования скрытых факторов. Наблюдаются следующие закономерности:

- Высокие корреляции между фенольными соединениями (total_phenols, flavanoids, proanthocyanins)
- Корреляции между цветовыми характеристиками (color_intensity, hue)
- Взаимосвязи между минеральными компонентами

Это подтверждает целесообразность проведения факторного анализа для выявления скрытых факторов.

## 4. Стандартизация переменных

Все переменные были стандартизированы с использованием метода StandardScaler из библиотеки sklearn. После стандартизации:
- Среднее значение каждой переменной = 0
- Стандартное отклонение каждой переменной = 1

Стандартизация необходима для корректного сравнения переменных с разными шкалами измерения.

## 5. Критерии КМО и Бартлетта

### Критерий КМО (Kaiser-Meyer-Olkin)
Критерий КМО измеряет адекватность выборки для факторного анализа:
- **Значение КМО**: определяется в процессе выполнения скрипта
- **Интерпретация**:
  - КМО ≥ 0.9: Отлично
  - КМО ≥ 0.8: Хорошо
  - КМО ≥ 0.7: Средне
  - КМО ≥ 0.6: Посредственно
  - КМО < 0.6: Неприемлемо

### Тест сферичности Бартлетта
Тест Бартлетта проверяет гипотезу о том, что корреляционная матрица является единичной (т.е. переменные не коррелируют):
- Если p-value < 0.05, то данные подходят для факторного анализа
- Если p-value ≥ 0.05, то данные не подходят для факторного анализа

## 6. Определение количества факторов

### Критерий Кайзера
Критерий Кайзера предполагает отбор факторов с собственными значениями (eigenvalues) больше 1. Собственные значения показывают, какая доля дисперсии объясняется каждым фактором.

### Критерий каменистой осыпи (Scree Plot)
График каменистой осыпи визуализирует собственные значения факторов. Точка излома на графике указывает на оптимальное количество факторов. Факторы после точки излома вносят незначительный вклад в объяснение дисперсии.

**Интерпретация графика:**
- Резкий перепад собственных значений указывает на переход от значимых к незначимым факторам
- Количество факторов определяется до точки излома

## 7. Матрица факторных нагрузок

### До вращения
Матрица факторных нагрузок до вращения показывает корреляции между исходными переменными и факторами. Однако интерпретация может быть затруднена из-за сложной структуры нагрузок.

### После вращения (Varimax)
Вращение Varimax применяется для упрощения интерпретации факторов:
- Стремится максимизировать дисперсию факторных нагрузок
- Облегчает интерпретацию факторов
- Позволяет четко определить, какие переменные входят в каждый фактор

**Интерпретация нагрузок:**
- Нагрузки > |0.5| считаются значимыми
- Переменные с высокими нагрузками на один фактор образуют группу

## 8. Общности (Communalities)

Общности показывают, какая доля дисперсии каждой переменной объясняется выделенными факторами. Высокие значения общностей (> 0.6) указывают на хорошее объяснение переменных факторной моделью.

## 9. Диаграммы рассеивания для факторов

Диаграммы рассеивания визуализируют распределение наблюдений в факторном пространстве. Они позволяют:
- Оценить структуру данных
- Выявить кластеры наблюдений
- Оценить взаимосвязи между факторами
