# ПОДГОТОВКА К ЗАЩИТЕ ЛАБОРАТОРНОЙ РАБОТЫ ПО ФАКТОРНОМУ АНАЛИЗУ

## 📋 КРАТКОЕ ОПИСАНИЕ ПРОЕКТА

**Цель работы**: Изучение методов факторного анализа для выявления скрытых факторов в многомерных данных.

**Датасет**: Wine Dataset (178 наблюдений, 13 признаков) - результаты химического анализа вин.

**Основной файл**: `factor_analysis_with_library.py`

---

## 🔍 АНАЛИЗ КОДА

### Структура программы

Код выполняет факторный анализ в следующей последовательности:

1. **Загрузка и описание данных** (строки 23-41)
   - Загружает датасет Wine из sklearn
   - Выводит информацию о количестве наблюдений и признаков
   - Показывает первые строки данных

2. **Дескриптивный анализ** (строки 43-79)
   - Вычисляет описательную статистику (среднее, стандартное отклонение, минимум, максимум, квартили)
   - Проверяет пропущенные значения
   - Проверяет нормальность распределения (тест Шапиро-Уилка)
   - Создает гистограммы распределений переменных

3. **Корреляционный анализ** (строки 81-95)
   - Вычисляет корреляционную матрицу
   - Визуализирует корреляции в виде тепловой карты
   - Выявляет взаимосвязи между переменными

4. **Стандартизация переменных** (строки 97-108)
   - Использует StandardScaler для приведения переменных к единому масштабу
   - После стандартизации: среднее = 0, стандартное отклонение = 1

5. **Критерии КМО и Бартлетта** (строки 110-136)
   - **КМО (Kaiser-Meyer-Olkin)**: оценивает пригодность данных для факторного анализа
   - **Тест Бартлетта**: проверяет гипотезу о том, что переменные коррелируют
   - Оба критерия должны подтвердить пригодность данных

6. **Определение количества факторов** (строки 138-184)
   - Вычисляет собственные значения (eigenvalues)
   - Применяет **критерий Кайзера**: факторы с λ > 1
   - Строит **график каменистой осыпи** (Scree Plot)
   - Определяет оптимальное количество факторов

7. **Факторный анализ методом главных компонент** (строки 186-234)
   - Извлекает факторы без вращения
   - Вычисляет матрицу факторных нагрузок
   - Вычисляет общности (communalities)

8. **Вращение Varimax** (строки 236-259)
   - Применяет ортогональное вращение Varimax
   - Упрощает интерпретацию факторов
   - Создает матрицу нагрузок после вращения

9. **Диаграммы рассеивания** (строки 261-283)
   - Визуализирует распределение наблюдений в факторном пространстве
   - Позволяет выявить кластеры и выбросы

10. **Интерпретация результатов** (строки 285-305)
    - Интерпретирует факторы на основе переменных с высокими нагрузками (|нагрузка| > 0.5)
    - Вычисляет долю объясненной дисперсии

## 📚 КЛЮЧЕВЫЕ ПОНЯТИЯ ДЛЯ ЗАЩИТЫ

### 1. Факторный анализ - что это?

**Факторный анализ** - метод снижения размерности, который выявляет скрытые факторы, объясняющие корреляции между наблюдаемыми переменными.

**Цель**: Сократить количество переменных, сохранив максимальную информацию.

### 2. Методы факторного анализа

#### Метод главных компонент (PCA)
- Преобразует коррелированные переменные в некоррелированные линейные комбинации
- Использует собственные значения и собственные векторы корреляционной матрицы
- **Формула**: F = XW, где W - матрица весов из собственных векторов

#### Метод главных факторов
- Альтернативный метод извлечения факторов
- В коде используется PCA (метод главных компонент)

### 3. Критерии пригодности данных

#### Критерий КМО (Kaiser-Meyer-Olkin)
- **Формула**: KMO = Σr²ᵢⱼ / (Σr²ᵢⱼ + Σa²ᵢⱼ)
- **Интерпретация**:
  - ≥ 0.9: Отлично
  - ≥ 0.8: Хорошо
  - ≥ 0.7: Средне
  - ≥ 0.6: Посредственно
  - < 0.6: Неприемлемо

#### Тест сферичности Бартлетта
- **Гипотеза H₀**: Корреляционная матрица единичная (переменные не коррелируют)
- **Статистика**: χ² = -[(n-1) - (2p+5)/6] × ln|R|
- **Интерпретация**: p-value < 0.05 → данные подходят для факторного анализа

### 4. Определение количества факторов

#### Критерий Кайзера
- **Правило**: Выбираем факторы с собственными значениями (λ) > 1
- **Обоснование**: Если λ < 1, фактор объясняет меньше дисперсии, чем одна переменная

#### График каменистой осыпи (Scree Plot)
- Визуализирует собственные значения в порядке убывания
- **Точка излома** (эльбоу) указывает оптимальное количество факторов
- Факторы после точки излома вносят незначительный вклад

### 5. Матрица факторных нагрузок

**Факторная нагрузка** - корреляция между переменной и фактором.

**Интерпретация нагрузок**:
- |нагрузка| > 0.7: очень сильная связь
- 0.5 < |нагрузка| ≤ 0.7: сильная связь
- 0.3 < |нагрузка| ≤ 0.5: умеренная связь
- |нагрузка| ≤ 0.3: слабая связь

### 6. Общности (Communalities)

**Общность** - доля дисперсии переменной, объясняемая факторами.

**Формула**: h²ᵢ = Σl²ᵢⱼ (сумма квадратов нагрузок по всем факторам)

**Интерпретация**:
- h² > 0.7: хорошо объяснена
- 0.5 < h² ≤ 0.7: удовлетворительно
- h² ≤ 0.5: плохо объяснена

### 7. Вращение факторов

#### Зачем нужно вращение?
- Упрощает интерпретацию факторов
- Делает структуру нагрузок более четкой
- Каждая переменная имеет высокую нагрузку преимущественно на один фактор

#### Вращение Varimax
- **Тип**: Ортогональное вращение
- **Цель**: Максимизировать дисперсию квадратов нагрузок
- **Свойство**: Факторы остаются некоррелированными
- **Результат**: Упрощенная структура, легче интерпретировать

### 8. Собственные значения и дисперсия

**Собственное значение (λ)** показывает долю дисперсии, объясняемую фактором.

**Свойства**:
- Σλᵢ = p (количество переменных)
- Доля дисперсии фактора j: λⱼ/p × 100%
- Накопленная доля: Σλⱼ/p × 100%

### Теоретические вопросы

1. **Что такое факторный анализ?**
   - Метод снижения размерности для выявления скрытых факторов

2. **В чем разница между методом главных компонент и методом главных факторов?**
   - PCA: использует полную корреляционную матрицу
   - Метод главных факторов: использует восстановленную корреляционную матрицу

3. **Что такое факторные нагрузки?**
   - Корреляции между переменными и факторами

4. **Что такое общности?**
   - Доля дисперсии переменной, объясняемая факторами

5. **Зачем нужно вращение факторов?**
   - Упростить интерпретацию, сделать структуру более четкой

6. **В чем суть вращения Varimax?**
   - Ортогональное вращение, максимизирующее дисперсию квадратов нагрузок

7. **Как работает критерий Кайзера?**
   - Выбираем факторы с собственными значениями > 1

8. **Как интерпретировать график каменистой осыпи?**
   - Точка излома указывает оптимальное количество факторов

9. **Что показывает критерий КМО?**
   - Пригодность данных для факторного анализа

10. **Что проверяет тест Бартлетта?**
    - Гипотезу о том, что переменные коррелируют

### Практические вопросы

   - Переменные имеют разные единицы измерения и масштабы

3. **Какие результаты показали критерии КМО и Бартлетта?**
   - КМО: значение (зависит от выполнения кода)

4. **Сколько факторов было выделено?**
   - Зависит от результатов (обычно 3-4 по критерию Кайзера)
