РГЗ. Кластеризация
Цель работы: изучение методов кластеризации.
Программное обеспечение: по выбору студента, рекомендуется RStudio.
Задание
1. Выбрать массив данных (рекомендуются базы по ссылкам № 3-4 из
списка литературы), описать параметры. Примечание: тип задачи
«классификация», «кластеризация».
2. Провести дескриптивный анализ, оценить согласованность выборок с
нормальным распределением. В соответствии с результатами
обосновать выбор методов кластеризации. Проверить условия
решения задачи, в том числе выбранными методами.
3. Отобрать наиболее информативные признаки при необходимости.
4. Стандартизировать переменные.
5. Построить диаграммы рассеивания (составные диаграммы
рассеивания, категоризованные диаграммы рассеяния) по
выбранным переменным. Интерпретировать результаты, оценить
возможное количество кластеров, тип кластерной структуры.
6. Решить задачу кластеризации двумя методами (k-средних,
иерархический, EM, DBSCAN и др). Рекомендуется выбирать методы
из разных групп.
7. Оценить качество построенных моделей (в т.ч. расстояние между
кластерами, внутрикластерные расстояния, компактность кластеров,
центры кластеров, силуэт и т.д.). При необходимости рассчитать
внешние метрики.
8. Оценить значимость признаков.
9. Провести сравнительный анализ решений.
10. Исследовать влияние параметров одного из методов на
качество решения, оценить полученные результаты.
11. Интерпретировать результаты.
12. Оформить отчет.
Содержание отчета
1. Титульный лист.
2. Цель работы.
3. Описание исходных данных.
4. Результаты дескриптивного анализа.
5. Диаграммы рассеивания.
6. Интерпретация результатов (количество кластеров, форма).
7. Обоснование выбора методов кластеризации.
8. Параметры выбранных методов.
9. Оценка адекватности полученных решений. Описание кластеров,
характеристика метрик, значимость признаков.
10. Сравнительный анализ решений и интерпретация результатов.
11. Результаты исследования влияния параметров алгоритма на
качество решения.

Вопросы к защите и примеры практических заданий.
1. Постановка задачи кластеризации. Подготовка данных.
2. Классификация методов решения задачи кластеризации.
3. Метод k-средних. Условия применения метода. Параметры.
Процедура применения метода. Рекомендации по применению
метода. Модификации метода.
4. Метод DBSCAN. Условия применения метода. Параметры. Процедура
применения метода. Рекомендации по применению метода.
5. Иерархические методы кластеризации. Дендрограмма. Условия
применения метода. Параметры. Процедура применения метода.
Рекомендации по применению метода.
6. Метод EM. Условия применения метода. Параметры. Процедура
применения метода. Рекомендации по применению метода.
7. Типы кластерных структур. Формы кластеров.
8. Метрики для оценки близости объектов и кластеров. В т.ч. евклидово
расстояние, расстояние городских кварталов; метод одиночной
связи, метод полной связи, метод Варда.
9. Метрики для оценки качества кластеризации, внутренние и внешние.
В т.ч. силуэт, компактность, Rand и пр.
10. Для представленной структуры (диаграмма рассеивания)
обосновать выбор метода кластеризации.
11. По графику (диаграмма рассеивания с обозначением
принадлежности объектов кластерам) оценить эффективность
метода.
12. Рекомендации по выбору значений параметров для изучаемых
методов кластеризации. Достоинства и недостатки методов.
13. Оценка значимости признаков.
14. По представленным результатам оценить качество
кластеризации (метрики, силуэтная диаграмма).
