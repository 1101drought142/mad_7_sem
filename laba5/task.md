Лабораторная работа 5. Технический анализ. Паттерны
Цель работы: изучение основ технического анализа в трейдинге, получение
навыков определения паттернов, индикаторов.
Платформа – по выбору студента.
Задание
1. Ознакомиться с материалами по основам технического анализа (ссылки
1-5 из списка справочных материалов).
2. Рассмотреть примеры платформ для трейдинга (ссылки 17-18 из списка
справочных материалов).
3. На примере работы платформ проанализировать выделение паттернов,
определение индикаторов (ссылки 6-11, 15, 18 из списка справочных материалов).
4. Выбрать один из временных рядов (котировок), экспортировать данные
(ссылки 6-14 из списка справочных материалов).
5. Разработать алгоритм для определения тренда, линий сопротивления и
поддержки, одной из базовых фигур технического анализа, одного индикатора
(осциллятора). Рассматриваются базовые индикаторы RSI, MACD, MA; паттерны
«голова и плечи», «бриллиант», «клин», «двойное дно» и др. (ссылки 1-5 из списка
справочных материалов).
6. Разработать приложение на любом языке программирования для
тестирования алгоритма. Необходимы библиотеки для отображения графика
котировок, выделенных паттернов, тренда, линий поддержки и сопротивления.
7. Сравнить результаты работы алгоритма с результатами,
представленными на платформах (ссылки 9, 11, 16, 18 из списка справочных
материалов).
Содержание отчета
1. Описание временного ряда. График ряда в виде японских свечей.
2. Описание разработанного алгоритма.
3. Результаты применения алгоритма к выбранному ряду: тренд, линии
поддержки и сопротивления, обнаруженные паттерны, индикаторы и т.д.
4. Сравнение результатов анализа, полученных с помощью
разработанного алгоритма, и предоставляемых платформой.
