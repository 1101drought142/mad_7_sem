# Лабораторная работа 5. Технический анализ. Паттерны

## Описание

Реализация алгоритма технического анализа для определения:
- Тренда (на основе скользящих средних)
- Линий поддержки и сопротивления
- Паттерна "Двойное дно"
- Индикаторов: RSI, MACD, MA

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Запуск анализа

```bash
python technical_analysis.py
```

## Алгоритмы

### Определение тренда
- Используются скользящие средние MA(20) и MA(50)
- Тренд определяется по взаимному расположению средних

### Линии поддержки и сопротивления
- Поиск локальных минимумов (поддержка) и максимумов (сопротивление)
- Группировка близких уровней
- Выбор наиболее значимых уровней

### Паттерн "Двойное дно"
- Поиск двух локальных минимумов с допустимым отклонением
- Проверка наличия промежуточного пика
- Минимальное расстояние между днами

### Индикаторы
- **RSI(14)**: Относительный индекс силы, показывает перекупленность/перепроданность
- **MACD**: Конвергенция-дивергенция скользящих средних
- **MA**: Скользящие средние (20 и 50 периодов)

## Анализ временных рядов

### Методы визуализации

1. **Линейный график** - отображает динамику временного ряда с диапазоном High-Low

2. **Сезонная декомпозиция** - разбивает ряд на компоненты:
   - Тренд (долгосрочная тенденция)
   - Сезонность (периодические колебания)
   - Остаток (случайная составляющая)

3. **ACF и PACF** - автокорреляционный анализ:
   - Помогает определить параметры моделей ARIMA
   - Выявляет зависимости между значениями ряда с разными лагами

4. **Календарная тепловая карта** - выявляет:
   - Внутринедельные паттерны (активность по дням недели)
   - Внутримесячные паттерны (активность по месяцам)
   - Годовые тренды

5. **Прогноз с доверительным интервалом**:
   - Использует модель ARIMA для прогнозирования
   - Показывает область неопределенности (доверительный интервал 95%)
   - Помогает оценить возможные будущие значения
